VAISHNAVIIII'S BIRTHDAY SITE — SOURCE CODE

Files
- index.html: page content and structure
- style.css: design, responsive layout, and animations
- script.js: photo pop-ups, scroll effects, and interactions
- assets/: the photos and illustrated dream picture used by the site

To open: unzip the folder and open index.html in a browser. Keep style.css, script.js, and assets in the same folder as index.html.

To publish: upload the contents of this folder, including index.html, to your hosting service.

Privacy: the site contains personal photos and chat screenshots. A public website may be accessible to anyone with its link.
